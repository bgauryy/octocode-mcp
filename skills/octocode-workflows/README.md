# Octocode Workflows

This skill selects and composes sustained, coordinated, or role-based work without replacing the relevant domain skill.

Start with [SKILL.md](SKILL.md). The [catalog](references/catalog.md) routes task families; [composition](references/composition.md) defines the orchestrator-and-actor contract; [verification](references/verification.md) preserves one ledger and recovery rules.

Use it for an explicitly requested workflow, whole-system audit, role split, runtime surgery, handoff/resume, or resource-flow audit. A direct research, documentation, architecture, or other domain task starts with its domain skill instead.

Output is a concise selection or completion result; domain output formats win when they apply. Saved workflow reports use [output.md](output.md).
