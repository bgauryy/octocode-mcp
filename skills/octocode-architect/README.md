# Octocode Architect

Analyze architecture decisions and refactors against code, contracts, and runtime evidence.

Architect owns boundaries, dependency direction, critical paths, review angles, proof, gates, and change discipline. It does not select or orchestrate workflows.

For a coordinated method, whole-system audit, runtime surgery, role split, handoff, or shared verification, start with [Octocode Workflows](../octocode-workflows/SKILL.md). Its [composition contract](../octocode-workflows/references/composition.md#orchestrator-and-actor-contract) owns roles and ledger; its [AST/LSP techniques](../octocode-workflows/references/ast-lsp-workflows.md) use this skill's architecture checks and `octocode-research` tool semantics.

Start with [SKILL.md](SKILL.md); [output.md](output.md) sets the result format.
